## Informations générales

**OCR (Reconnaissance optique de caractères)** est un outil permettant d'extraire d'une image tous les éléments écrits.

## Comment l'utiliser

Vous pouvez l'utiliser en fournissant :
- une URL directe vers une image
- un fichier image local via le bouton d'import de fichier

L'outil identifie alors le contenu écrit, l'affiche, identifie la langue et le traduit via Google Translate.

## Cas d'usage

- Aider à traduire le texte d'une image sans avoir à le recopier manuellement

## Notes importantes

- L'outil a des limites selon la lisibilité du texte et les langues dans lesquelles il est écrit
