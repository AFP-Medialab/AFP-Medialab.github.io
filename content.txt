Verification Plugin: Comprehensive Technical Documentation & Component Repository
Official Descriptive Name: Fake News Debunker by InVID, WeVerify, and veraAI
Target Audience: Investigative Journalists, Fact-Checkers, OSINT Researchers, Human Rights Defenders
1. Executive Summary & Structural Architecture
The Verification Plugin operates as a modular, browser-based "Swiss army knife" designed to address verification challenges in digital media. Initially established under the European Union's Horizon 2020 InVID Project (2016–2018), the suite was subsequently scaled through the WeVerify Project (2018–2021) and was updated through the veraai.eu Research and Innovation Action (2022–2025) and the DeFacto2 EDMO hub project.

The application's architecture is translation-driven and relies on Tab-Separated Values (.tsv) configuration files stored within centralized localization repositories. These files map interface elements directly to technical functions. This structural mapping ensures modular scaling, allowing experimental AI features to be integrated or modified without disrupting the underlying user interface framework.

An interactive intake dashboard that guides operators through a step-by-step diagnostic questionnaire based on the properties of the media file under evaluation. Video Analysis
Active
Automates contextual structured scraping on hosting endpoints (such as YouTube and Facebook). It fetches deep source data including exact upload times across time zones, channel verification tags, and historical engagement anomalies. It also extracts comment structures to map source links shared by viewers or spot coordinated bot responses.
Video Keyframe Fragmentation
Active
Breaks down video files (.mp4, .mkv, .avi) or remote URLs (YouTube, Facebook, DailyMotion) into static visual frames using sub-shot segmentation filters. Each extracted keyframe features an integrated multi-engine shortcut to run immediate reverse queries across Google Lens, Bing, Yandex, Baidu, TinEye, and the Database of Known Fakes (DBKF).
YouTube Thumbnails
Active
A rapid sorting alternative that bypasses full video processing. It automatically grabs the four default system-generated preview images directly via the YouTube API. This lets analysts execute quick reverse image queries to detect recycled media before running more time-intensive frame breakdowns.
Magnifier
Active
A high-resolution image inspection lens offering up to 20x magnification on local uploads, web URLs, or cloud-hosted links. It includes quick-action tools to adjust sharpness, contrast, and orientation. Crucially, it provides a mirror-flip function designed to counter bad-actor evasion techniques that modify spatial orientation to dodge automated reverse index matches.
Metadata Viewer
Active
Examines structural metadata profiles across files, exposing embedded EXIF, IPTC, and XMP blocks. It extracts camera hardware signatures, editing software logs, lens configurations, and spatial GPS coordinates to verify historical provenance.
Image Forensics
Active
An advanced suite for uncovering hidden image alterations. It features Error Level Analysis (ELA) to spotlight non-uniform JPEG compression rates that hint at digital splicing. It also applies specialized matrix filters to scan for noise consistency, edge anomalies, and cloned pixel blocks.
Advanced X Search (X Search / Twitter Search)
Active / Modified
Bypasses default frontend algorithm restrictions to construct detailed custom search queries. It allows users to pinpoint exact date windows down to the hour, configure Boolean chains, and isolate specific handles or regional coordinates during breaking-news incidents.
Geolocalizer
Active / Beta
An AI-assisted geolocation estimation tool that parses topographical markers, unique architecture styles, and environmental landmarks when standard metadata is missing. It returns recommended coordinate zones alongside matching visual evidence to help analysts manually confirm locations.
Video Rights Management
Active
Assesses platform licensing guidelines and distribution access parameters for online video URLs. This helps newsrooms quickly evaluate the legal parameters and ownership chains of user-generated videos during active breaking news cycles.
Chatbot Workspace Helper
Active
An internal interactive assistant built directly into the toolkit to answer operational queries, explain forensic metrics, and provide guidance on standard verification methods.

4. Translation Management Pipeline
To ensure localization files render properly in production environments, developers and localization engineers follow strict asset pipelines:
TSV Editing Constraints: Translation additions must use precise tab separations. For interior quotation markings, single quote marks (\') are required, as double quotes (\") break the parsing compiler.
Compilation Rules: Pre-deployment builds use automated scripts (such as localized Jupyter extraction tools) to parse the source .tsv files and compile them into optimized production JSON schemas (e.g., public/locales/[lang]/components/NavItems/tools/Assistant.json).
Caching Infrastructure: The live browser extension uses a daily cache layer controlled by specific version variables (VITE_TRANSLATION_TAG) to balance server load while delivering updated strings to users worldwide.
