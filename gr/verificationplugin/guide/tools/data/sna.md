## Γενικές πληροφορίες

**Social Network Analysis (SNA)** παρέχει εργαλεία για τη σύλληψη, ανάλυση και οπτικοποίηση δεδομένων κοινωνικών μέσων σε πραγματικό χρόνο. Σας επιτρέπει να καταγράφετε δραστηριότητα γύρω από ένα θέμα, hashtag ή λογαριασμό και να αναλύετε το προκύπτον δίκτυο αλληλεπίδρασης για την ταυτοποίηση βασικών παραγόντων, ροών πληροφοριών και συντονισμένης συμπεριφοράς.

## Πώς να το χρησιμοποιήσετε

Χρησιμοποιήστε τα στοιχεία ελέγχου εγγραφής για να συλλάβετε δεδομένα από μια πηγή κοινωνικών μέσων (ρυθμίστε τον στόχο στο μενού ρυθμίσεων ή στο εργαλείο X Search). Μόλις συλλεχθούν τα δεδομένα, ανοίξτε το εργαλείο SNA για να οπτικοποιήσετε το δίκτυο.

**Σημαντικό:** βεβαιωθείτε ότι έχετε ανανεώσει τη σελίδα που θέλετε να ανακτήσετε μετά την εκκίνηση της εγγραφής.

Μπορείτε επίσης να μεταφορτώσετε δεδομένα που συλλέχθηκαν προηγουμένως για ανάλυση.

## Πώς λειτουργεί

Αρχικά, το εργαλείο αναρτά τον ιστότοπο για να ανακτήσει tweets ή βίντεο TikTok σε μορφή συλλογής κατάλληλης για ανάλυση.

Στη συνέχεια δημιουργεί μετρικές όπως χρονική κατανομή, δραστηριότητα λογαριασμών, συντονισμένη συμπεριφορά, αναφορές, hashtag, σύννεφο λέξεων και σημασιολογική ομοιότητα.

Μπορείτε να προσθέσετε μια παλαιά συλλογή αποθηκευμένη στα τοπικά αρχεία σας σε μια υπάρχουσα στο πρόσθετο.

Σημειώστε ότι οι συλλογές αποθηκεύονται στο IndexDB του προγράμματος περιήγησής σας· εάν θέλετε να διατηρήσετε μια συλλογή για μεγάλο χρονικό διάστημα, βεβαιωθείτε ότι την έχετε κατεβάσει.

## Περιπτώσεις χρήσης

- Ταυτοποίηση βασικών λογαριασμών που κινούν μια αφήγηση ή hashtag
- Ανίχνευση ομάδων λογαριασμών που ενδέχεται να συντονίζουν ενίσχυση περιεχομένου
- Χαρτογράφηση της δομής μιας επιχείρησης πληροφοριών
- Ανάλυση του τρόπου εξάπλωσης ενός περιεχομένου μέσα από ένα δίκτυο με την πάροδο του χρόνου
