## Γενικές πληροφορίες

**Magnifier** είναι ένας φακός επιθεώρησης εικόνας υψηλής ανάλυσης που προσφέρει μεγέθυνση έως 20x σε τοπικές μεταφορτώσεις, web URLs ή συνδέσμους που φιλοξενούνται στο cloud. Περιλαμβάνει εργαλεία γρήγορης ενέργειας για ρύθμιση της ευκρίνειας, της αντίθεσης και του προσανατολισμού. Σημαντικά, παρέχει λειτουργία αντικατοπτρισμού σχεδιασμένη να αντιμετωπίζει τεχνικές αποφυγής κακόβουλων χρηστών που τροποποιούν τον χωρικό προσανατολισμό για να αποφύγουν τις αυτόματες αντιστοιχίσεις ευρετηρίου αντίστροφης αναζήτησης εικόνας.

## Πώς να το χρησιμοποιήσετε

Μπορείτε να το χρησιμοποιήσετε παρέχοντας:
- έναν άμεσο σύνδεσμο URL σε εικόνα σε οποιαδήποτε ιστοσελίδα
- ένα τοπικό αρχείο εικόνας μέσω του κουμπιού μεταφόρτωσης αρχείου
- κάνοντας δεξί κλικ σε οποιαδήποτε εικόνα στον φυλλομετρητή

Χρησιμοποιήστε το ρυθμιστικό μεγέθυνσης για εστίαση σε περιοχές ενδιαφέροντος. Ρυθμίστε την ευκρίνεια και την αντίθεση για να αποκαλύψετε λεπτομέρειες που δεν είναι ορατές στην τυπική ανάλυση. Χρησιμοποιήστε τη λειτουργία αντικατοπτρισμού για να αντιστρέψετε οριζόντια ή κατακόρυφα αναποδογυρισμένες εικόνες.

## Περιπτώσεις χρήσης

- Επιθεώρηση λεπτών λεπτομερειών που ενδέχεται να υποδηλώνουν επεξεργασία εικόνας (π.χ. κλωνοποίηση, ίχνη splicing)
- Εξέταση κειμένου, λογοτύπων ή αναγνωριστικών σε εικόνες χαμηλής ανάλυσης
- Αντιστροφή χωρικά αναποδογυρισμένων εικόνων για την ενεργοποίηση ακριβών αντίστροφων αναζητήσεων εικόνας
- Επαλήθευση οπτικής συνοχής σε διαφορετικά τμήματα μιας εικόνας

## Σημαντικές σημειώσεις

- Η μεγέθυνση δεν προσθέτει πληροφορίες που δεν υπάρχουν ήδη στην αρχική εικόνα. Εικόνες πολύ χαμηλής ανάλυσης θα παραμείνουν pixelated σε υψηλά επίπεδα ζουμ.
- Η λειτουργία αντικατοπτρισμού είναι ιδιαίτερα χρήσιμη όταν το περιεχόμενο έχει σκόπιμα αναποδογυριστεί για να αποφύγει την αντίστροφη ανίχνευση εικόνας.
