## General information

**XNetwork** is a network analysis tool focused on X (formerly Twitter) that traces the dissemination vectors of narratives and content across the platform. It maps how information spreads, identifies key amplification nodes, and surfaces patterns of coordinated inauthentic behaviour.

## How to use it

Configure a search target (keyword, hashtag, or account) and launch the network capture. Once data is collected, the tool visualises the resulting interaction network.

## How it works

The tool builds a relational graph from X interaction data (retweets, replies, mentions) and applies network analysis algorithms to identify community structures, influential accounts, and coordinated amplification patterns. It draws on techniques used in the Social Network Analysis toolkit to map the spread of specific narratives.

## Use cases

- Mapping how a piece of misinformation spreads through the X network
- Identifying accounts that act as primary amplification hubs
- Detecting clusters of accounts engaged in coordinated sharing behaviour
- Analysing the network structure around a specific hashtag or event
