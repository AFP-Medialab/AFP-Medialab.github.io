## General information

**XNetwork** is a social network analyse. It searches a semantic input through social networks such as Instagram, X, Tik Tok, and provides a repartition on where the content is more present. It is a social network search engine.

## How to use it

Enter a phrase about a subject, and then analyse the result on how the subject has appeared in all the social network indexed by google.

## Use cases

- Evaluate the virality of some content (where it has spread, how much is it shared, etc.)
