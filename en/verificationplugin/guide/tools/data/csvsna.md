## General information

**CSV Social Network Analysis** (CSV SNA) allows you to perform social network analysis on datasets exported from social media platforms, including historical data from CrowdTangle or similar tools. By uploading a CSV file containing post or interaction data, you can visualise the network of accounts sharing or engaging with a piece of content.

## How to use it

Export data from your social media monitoring tool as a CSV file. Upload the file using the file upload button. The tool will parse the data and generate a network visualisation showing relationships between accounts and the flow of content.

## How it works

The tool processes the CSV data to build a graph of account interactions. It then applies network analysis algorithms to identify influential nodes, clusters, and propagation patterns. Results are displayed as an interactive network graph.

## Use cases

- Analysing the spread of a piece of content across a social platform
- Identifying coordinated inauthentic behaviour from exported platform data
- Visualising information cascades from historical datasets

## Supported formats

- CSV exports from CrowdTangle
- Standard CSV files with account and interaction columns
