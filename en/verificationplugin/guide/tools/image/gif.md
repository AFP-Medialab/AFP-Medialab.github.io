## General information

**CheckGIF** analyses animated GIFs and video clips to detect manipulation. A common misinformation technique involves extracting individual frames from a video and presenting them out of context, or creating a GIF that misrepresents the original sequence of events.

This tool helps verify the authenticity of animated content by examining frame sequences, timing, and consistency.

## How to use it

You can use it by providing:
- a direct link to a GIF or short video on any web page
- a local GIF file via the file upload button
- by right-clicking on a GIF in the browser and selecting the contextual menu option

## How it works

The tool extracts and displays individual frames from the animated content, allowing you to inspect each frame for signs of editing, splicing, or out-of-sequence assembly. It also provides frame timing information to help detect unnatural speed changes.

## Use cases

- Checking whether a GIF has been sped up, slowed down, or reversed
- Verifying that a GIF accurately represents the original video source
- Detecting frames that have been inserted or removed from an animation
