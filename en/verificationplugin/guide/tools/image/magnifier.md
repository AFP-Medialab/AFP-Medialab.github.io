## General information

**Magnifier** is a high-resolution image inspection lens offering up to 20x magnification on local uploads, web URLs, or cloud-hosted links. It includes quick-action tools to adjust sharpness, contrast, and orientation. Crucially, it provides a mirror-flip function designed to counter bad-actor evasion techniques that modify spatial orientation to dodge automated reverse image index matches.

## How to use it

You can use it by providing:
- a direct URL to an image on any web page
- a local image file via the file upload button
- by right-clicking on any image in the browser

Use the magnification slider to zoom in on areas of interest. Adjust sharpness and contrast to reveal details not visible at standard resolution. Use the mirror-flip function to reverse horizontally or vertically flipped images.

## Use cases

- Inspecting fine details that may indicate image manipulation (e.g. cloning, splicing artefacts)
- Examining text, logos, or identifiers in low-resolution images
- Reversing spatially flipped images to enable accurate reverse image searches
- Verifying visual consistency across different parts of an image

## Important notes

- Magnification does not add information that is not present in the original image. Very low-resolution images will remain pixelated at high zoom levels.
- The mirror-flip function is particularly useful when content has been deliberately flipped to evade reverse image detection.
