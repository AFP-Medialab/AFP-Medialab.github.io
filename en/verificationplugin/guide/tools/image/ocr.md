## General information

**OCR (Optical Caracter Recognition)** is a tool to extract from an image every written elements.

## How to use it

You can use it by providing:
- a direct URL to an image
- a local video file via the file upload button

The tool will then identify the written content, display it, identify the language and translate it using google translate.

## Use cases

- Help to translate text from an image without having to copy it manually

## Important notes

- The tool has limitations depending on how visible the text is and on what languages it is written in
