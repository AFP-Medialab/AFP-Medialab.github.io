## General information

**Archiving** allows you to create permanent, timestamped snapshots of web pages for evidentiary and preservation purposes. When reporting on or fact-checking online content, it is essential to preserve the original state of a page, as content can be deleted or modified after publication.

## How to use it

Enter the URL of the web page you want to archive. The tool will submit it to one or more web archiving services and return a link to the archived snapshot.

## Supported archiving services

- Internet Archive (archive.org / Wayback Machine)
- Archive.today (archive.ph)

## How it works

The tool sends a request to the selected archiving service, which takes a snapshot of the page at the current moment and stores it permanently. The returned URL can be used to access the archived version at any time in the future, even if the original page is deleted or modified.

## Use cases

- Preserving evidence of deleted social media posts or web pages
- Creating a verifiable, timestamped record of online content for editorial use
- Archiving source material before it disappears during a breaking news event

## Tips

- Archive pages as soon as you find them — content can disappear quickly
- Some pages (behind login walls, dynamic JavaScript-heavy sites) may not archive perfectly
