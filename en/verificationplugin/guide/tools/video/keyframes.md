## General information

**Video Keyframe Fragmentation** breaks down video files or remote URLs into static visual frames using sub-shot segmentation filters. Each extracted keyframe features an integrated multi-engine shortcut to run immediate reverse image queries, making it easy to trace the origin or prior use of video content.

## How to use it

You can use it by providing:
- a video file (.mp4, .mkv, .avi) via the file upload button
- a remote URL from a supported platform (YouTube, Facebook, DailyMotion)

## How it works

The tool segments the video into representative frames at key scene changes. Each extracted frame is presented with one-click shortcuts to launch reverse image searches across multiple engines simultaneously.

## Supported reverse image search engines

- Google Lens
- Bing
- Yandex
- Baidu
- TinEye
- Database of Known Fakes (DBKF)

## Use cases

- Tracing whether video footage has been recycled from an earlier event
- Finding the original source of a clip circulating out of context
- Identifying specific moments within a video for deeper investigation

## Important notes

- Frame extraction quality depends on the video resolution and encoding.
- Running reverse queries across all engines simultaneously gives the broadest coverage for detecting recycled content.
