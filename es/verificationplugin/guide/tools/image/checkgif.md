## Información general

**CheckGIF** toma como entrada dos imágenes similares y las superpone sobre la misma base para crear un GIF con anotaciones que faciliten la identificación de las diferencias entre ambas. Funciona con imágenes ligeramente alteradas porque utiliza una comparación homográfica que permite superponer las imágenes.

## Cómo usarlo

Puede utilizarlo proporcionando:
- dos URL directas a las imágenes
- dos archivos de imagen locales mediante el botón de carga de archivos

La herramienta las superpone y permite añadir anotaciones para la imagen supuestamente falsa y también para la original. Puede editar el contenido y el estilo de las anotaciones (por ejemplo, si las necesita en un idioma no disponible en el plugin). A continuación, puede descargarlas como GIF o MP4.

## Cómo funciona

La herramienta compara las dos imágenes e intenta superponerlas mediante comparación homográfica. Produce un error si no son lo suficientemente similares.

## Casos de uso

- Elemento de comunicación para mostrar rápidamente la imagen falsa y la original
- Para imágenes falsas cuya alteración no es lo suficientemente visible, la alteración queda resaltada por el formato GIF
