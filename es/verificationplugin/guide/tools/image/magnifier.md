## Información general

**Magnifier** es una lupa de inspección de imágenes en alta resolución que ofrece hasta 20x de aumento en cargas locales, URLs web o enlaces alojados en la nube. Incluye herramientas de acción rápida para ajustar la nitidez, el contraste y la orientación. De manera destacada, proporciona una función de inversión especular diseñada para contrarrestar las técnicas de evasión utilizadas por actores malintencionados que modifican la orientación espacial para eludir las coincidencias de índices de búsqueda inversa de imágenes automatizadas.

## Cómo usarlo

Puede usarlo proporcionando:
- una URL directa a una imagen en cualquier página web
- un archivo de imagen local mediante el botón de carga de archivos
- haciendo clic derecho sobre cualquier imagen en el navegador

Use el control deslizante de aumento para ampliar las áreas de interés. Ajuste la nitidez y el contraste para revelar detalles no visibles a resolución estándar. Use la función de inversión especular para revertir imágenes volteadas horizontal o verticalmente.

## Casos de uso

- Inspeccionar detalles finos que puedan indicar manipulación de la imagen (p. ej., artefactos de clonación o empalme)
- Examinar texto, logotipos o identificadores en imágenes de baja resolución
- Revertir imágenes volteadas espacialmente para permitir búsquedas inversas de imágenes precisas
- Verificar la coherencia visual en diferentes partes de una imagen

## Notas importantes

- El aumento no añade información que no esté presente en la imagen original. Las imágenes de muy baja resolución seguirán apareciendo pixeladas a altos niveles de zoom.
- La función de inversión especular es especialmente útil cuando el contenido ha sido deliberadamente volteado para evadir la detección mediante búsqueda inversa de imágenes.
